# Hemoglobin Cooperativity Underpins Wasserman's Anaerobic Threshold: A Call to Revisit the Critical Capillary PO2

## **1. Overview**
This repository contains the R code to reproduce Karlman Wasserman's 1994 model where capillary partial pressure of oxygen declines 
as function of fractional capillary length. 

## **Content**
The repository contains the following files:
- `Capillary_PO2_Model_Wasserman.R` -> The code file reproducing Wasserman's capillary PO2 model
- `Ligation_state_Figure.R` -> Code from previously published figure producing the standard oxygen dissociation curve and the hemoglobin ligation states at the inflection point, as well as a plot where the axis are swapped.
- `SHbO2CO2_Dash_2016_Adair.R` -> R code from previous publication the is called in the file `Ligation_state_Figure.R` to produce the corresponding plot
- `Schematic Figure.pptx` -> A powerpoint file creating with the schematic figure linking Fick's principle, Fick's law of diffusion and the S-shaped oxygen dissociation curve
- `session_info.txt` -> Auto-generated R session details for reproducibility.
- The plots produced by the code files above as pdf and tiff
